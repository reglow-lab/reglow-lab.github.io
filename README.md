# Re:Glow GitHub Pages

Re:Glow — Tiny Lights & Little Gadgets の1ページサイトです。

## GitHub Pagesで公開する

1. GitHub Organization `reglow-lab` に `reglow-lab.github.io` という **Public** リポジトリを作成します。
2. このフォルダ内の `index.html` と `assets/` をリポジトリ直下にアップロードします。
3. GitHubの **Settings → Pages** を開きます。
4. **Build and deployment → Source** を `Deploy from a branch` にします。
5. Branchを `main`、Folderを `/(root)` にして保存します。
6. 公開URLは通常 `https://reglow-lab.github.io/` になります。

## 構成

- `index.html` : 本体
- `assets/gacha.png` : 無限ガチャ・キーホルダー
- `assets/crystal.png` : 光るクリスタル
- `assets/firefly.png` : 群れる電子ホタル

フォントは Google Fonts の Noto Sans JP を使用しています。
